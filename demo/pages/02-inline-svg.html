Four ways to set the colour

fill attribute
style="fill:..."
<style> inside the svg
currentColor

The page stylesheet does not reach inside an inline <svg>, so a rule such as svg circle { fill: red } in the page CSS is ignored. Colour the artwork from inside the SVG: presentation attributes, its own style attributes, a <style> element, or currentColor fed by a color attribute on the root.

Gradient page furniture background-image: url(brand-gradient.svg)

CSS gradient functions are not supported, but an SVG file used as a background image gives the same result, stretched with background-size and clipped by border-radius.
